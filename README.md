# any2enforce

把常用编程语言自动转换为 **EnforceScript**（Arma Reforger / Enfusion 引擎脚本语言）的转换工具。
当前（v0.1）实现 **Python → EnforceScript** 前端；架构为多语言预留（Java / C# / TypeScript）。

**核心承诺（已用真实编译器兑现）**：转换成功 = 语义可信。无法 1:1 映射的构造一律产出
分级诊断并在输出中留 `[any2enforce:error]` / `TODO[...]` 标记，绝不静默生成错代码。

## 快速开始

```bash
pip install -e .          # Python >= 3.11，零第三方依赖
python -m pytest -q       # 54 个测试

# 转换
any2enforce examples/demo.py --out build/demo.c
any2enforce examples/training_lab.py --out build/training_lab.c --prefix LAB_

# CI：有 error 诊断即非零退出
any2enforce src/ --out build/ --fail-on-error

# 命名空间：EnforceScript 全项目一个命名空间，全局函数用前缀防撞名
any2enforce examples/train_mlp.py --out build/train_mlp.c --prefix T_
```

## 验证史（为什么这些映射可信）

1. **语料校准**：用 6568 个真实 Reforger `.c` 文件（`_reforger_code_full_v2/scripts`）批量
   探测语法，逐条对照 —— 详见 `docs/VERIFY.md`；
2. **真机编译验证**：验证包（`verify/`）在用户的 Workbench 里逐个编译/运行，所有 ⚠ 语法点
   定案（含 5 个"确认不存在"：三元运算符、`Math.Abs`、float `%`、运算符重载、`char`）；
3. **运行时定案**：int 除法=`/` 是 float 除法、基类构造参数隐式转发、`map.Contains`、
   `ScriptInvoker` 回调、`Math.E` 存在、**float = float32** 等；
4. **ML 数值对拍**：生成代码与 Python 参考跨 3 类别 8/8 数值一致；训练曲线形态一致
   （float32 精度差异已定案）。

关键定案清单见 [`docs/VERIFY.md`](docs/VERIFY.md)（⚠ 区已全部清零）。

## 流水线

```
Python 源码 → PythonFrontend（stdlib ast）→ IR → Analyzer（类型解析/字段上提）
→ EnforceBackend（生成 .c）→ [Workbench ValidateScripts 校验闭环]
```

设计铁律：
- 前端不产 EnforceScript 文本，后端不解析源语言 —— 新增语言只写一个 frontend；
- 一切无法精确映射的构造必须产生诊断，禁止猜测生成；
- 生成文件头自动加 `// Generated by any2enforce — DO NOT EDIT`。

完整设计见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## v0.1 支持范围（Python 子集）

| 支持 | 说明 |
|---|---|
| 模块级函数、类（单继承）、静态方法 | `__init__` → 构造函数；`self.x = v` → 字段上提（`m_` 前缀，裸访问）；基类构造参数隐式转发 |
| 类型注解 | `int/float/bool/str`、`list[T]→array<T>`、`dict[K,V]→map<K,V>`、`set[T]→set<T>`、`Optional`、用户类（自动 `ref`） |
| 控制流 | `if/elif/else`、`while`、`for i in range(...)`（含负步进）、`for x in list → foreach`、三元 → if/else 展开、块作用域变量自动上提 |
| 表达式 | 算术/比较/逻辑、`f"..."`/`%` → `string.Format`、`len()`、`print→Print/PrintFormat`、`min/max/abs` 类型分派、列表/字典字面量、map `[]` 读写、`x in c → c.Contains(x)`、内联数组实参 |
| 其他 | 默认参数、`list.append→Insert`、`super().method→super.Method`、`--prefix` 全局函数前缀 |

| 不支持（v0.1，报错并留标记） | 说明 |
|---|---|
| `try/except`、`with`、`global/nonlocal`、`del`、`raise`、生成器 `yield` | 建议改写为返回值/错误码模式 |
| `lambda`/闭包、嵌套函数 | 后续用 `ScriptInvoker` 回调（已定案可用） |
| `*args`/`**kwargs`、关键字实参、推导式、`tuple`、多继承、`@property`、装饰器 | 手动展开或等 v0.2 |

## 已知限制（诚实声明）

1. EnforceScript `float` = **float32**：生成代码与 Python float64 参考只保证近似一致
   （ML 训练本就是 float32 标准，无碍）；
2. 触碰动态特性的 Python 必然需要人工改写 —— 工具把能自动的部分自动掉、把不能的部分精确暴露；
3. 字段上提对"仅在部分分支赋值"的字段按类型默认值声明，与 Python 的 `AttributeError`
   语义不同 → 会告警；
4. 无 Workbench 环境时金样只保证文本稳定；`--validate` 可接入真机编译闭环。
